# Guías de Componentes

## Objetivo
Establecer estándares para la creación y composición de componentes en React.

## Alcance
Componentes de UI y de negocio.

## Cuándo consultar este documento
Al crear nuevos componentes o modificar existentes.

## Información
- **Composición**: Separar lógica (hooks) de la presentación (JSX).
- **Props**: Utilizar interfaces de TypeScript explícitas para todas las props.
- **Formularios**: Utilizar Formik y Yup para validaciones.
- **Tablas**: Uso de `@tanstack/react-table` para el manejo avanzado de datos en tablas.
- **Storybook**: Los componentes UI puros deben documentarse y probarse en Storybook (configurado en `.storybook/`).
- **Iconos**: Uso de `lucide-react`.
