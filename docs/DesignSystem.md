# Design System

## Objetivo
Documentar los tokens de diseño y reglas visuales del proyecto.

## Alcance
CSS, temas, variables globales, y recursos visuales.

## Cuándo consultar este documento
Al aplicar estilos o integrar nuevos elementos a la UI.

## Información
- **Estilos**: Uso de CSS nativo/módulos en `styles/` y `index.css`.
- **Identidad Visual**: Regido por los colores, tipografías y espaciados definidos en `IdentidadVisual.md`.
- **Responsive**: Uso de media queries (Mobile First preferentemente) en CSS.
- **Tokens**: Variables CSS definidas en la raíz del documento (e.g. `--primary-color`).
