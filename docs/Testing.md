# Testing Frontend

## Objetivo
Definir la estrategia y herramientas para pruebas en el Frontend.

## Alcance
Pruebas de componentes, integración y E2E en MesaFacil.UI.

## Cuándo consultar este documento
Al escribir pruebas para componentes o lógica del frontend.

## Información
- **Unit/Integration**: Configurado con **Vitest** (`@vitest/browser` y `@vitest/coverage-v8`).
- **UI Testing**: **Storybook** para testeo visual y documentación de componentes aislados (`@storybook/addon-vitest`).
- **E2E Testing**: Integrado o planeado con **Playwright** (`playwright` está como dependencia de desarrollo).
