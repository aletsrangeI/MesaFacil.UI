# Definition of Done (DoD)

Before marking a feature or task as complete, ensure the following criteria are met:

1.  **Functionality:** The code meets the acceptance criteria defined in the ticket.
2.  **Architecture Compliant:**
    *   State is managed correctly (RTK Query for remote, Redux slices/context for local).
    *   SDUI is utilized for dynamic forms (`<FormGenerator>`).
    *   TanStack Table is used for any data grids.
3.  **Routing & Security:**
    *   New routes are registered in `AppRouter.tsx` and wrapped with appropriate `RequireAccess` guards.
    *   Sidebar links match the exact route paths.
4.  **Styling:**
    *   No inline styles or hardcoded hex colors.
    *   Strict adherence to CSS variables defined in `src/styles/tokens.css`.
5.  **Quality:**
    *   TypeScript types/interfaces are defined. No `any` types unless strictly necessary.
    *   Code passes all linting (`npm run lint`).
    *   Tests pass and coverage is maintained or improved.
6.  **Code Gen:** If backend APIs changed, `npm run api:gen` was executed and the autogenerated file is committed.
